# 📚 Biblioteca Digital UniFECAF

> Interface web responsiva desenvolvida para facilitar o acesso dos estudantes da UniFECAF a livros, materiais acadêmicos e conteúdos de apoio à aprendizagem.

---

## 📖 Sobre o projeto

A **Biblioteca Digital UniFECAF** é uma interface web desenvolvida a partir de um protótipo de baixa fidelidade, transformando sua estrutura inicial em uma experiência digital mais organizada, intuitiva, responsiva e acessível.

O projeto apresenta uma proposta de biblioteca digital voltada aos estudantes, reunindo informações sobre o acervo, conteúdos em destaque, unidades e canais de contato.

A interface foi desenvolvida exclusivamente com **HTML5 e CSS3**, mantendo a organização geral apresentada no protótipo e aplicando decisões próprias de identidade visual, tipografia, imagens, espaçamentos e elementos interativos.

---

## 🎯 Objetivo

O principal objetivo do projeto é criar uma interface simples e intuitiva que facilite a localização de conteúdos e informações da biblioteca.

A página foi organizada para permitir que o estudante possa:

- 📚 Conhecer a biblioteca;
- 🔎 Explorar os livros disponíveis;
- 📖 Visualizar informações adicionais sobre os livros;
- 📍 Consultar as unidades;
- 🗺️ Acessar a localização das unidades;
- 📞 Encontrar os canais de contato;
- 💻 Utilizar a interface em computadores;
- 📱 Acessar a biblioteca também pelo smartphone.

---

## ✨ Funcionalidades

### 🧭 Navegação

- Menu de navegação com acesso às principais seções;
- Navegação por âncoras dentro da própria página;
- Botão para retornar ao início da página.

### 📚 Livros

- Catálogo com 6 livros;
- Imagens ilustrativas para cada livro;
- Título e descrição dos materiais;
- Recurso **"Saiba mais"** para apresentar informações complementares;
- Organização dos livros em cards.

### 🏫 Unidades

- Apresentação das unidades;
- Imagens dos campi;
- Informações sobre cada unidade;
- Links para localização pelo Google Maps.

### 📞 Contato

- E-mail;
- Telefone;
- Endereço;
- Horário de atendimento.

### 📱 Responsividade

- Layout adaptado para desktop;
- Layout adaptado para smartphones;
- Reorganização dos conteúdos para telas menores;
- Elementos dimensionados para facilitar a navegação em dispositivos móveis.

### ♿ Acessibilidade

- Textos alternativos nas imagens;
- Estrutura semântica em HTML;
- Elementos interativos nativos;
- Navegação por teclado;
- Destaque visual para elementos em foco;
- Contraste adequado entre textos e fundos.

## 🎨 Identidade visual

A identidade visual foi desenvolvida com base na proposta institucional da UniFECAF, utilizando principalmente tons de azul e detalhes em dourado.

### 🎨 Paleta de cores

| Cor | Código | Aplicação |
| :--- | :--- | :--- |
| 🔵 Azul principal | `#004B76` | Títulos, navegação e elementos estruturais |
| 🔵 Azul secundário | `#1687B8` | Botões e elementos de interação |
| 🟡 Dourado | `#D6A84F` | Destaques e foco de navegação |
| ⚪ Branco | `#FFFFFF` | Fundo principal |
| ◻️ Cinza-claro | `#F2F4F5` | Separação entre seções |
| ⚫ Cinza-escuro | `#202428` | Textos |

### 🔤 Tipografia

**Montserrat**  
Utilizada principalmente em títulos e elementos de maior destaque.

**Open Sans**  
Utilizada em textos, descrições e conteúdos informativos, priorizando a legibilidade.

**Poppins**  
Utilizada pontualmente em botões, categorias e elementos complementares.

---

## 🖥️ Responsividade

A interface foi desenvolvida pensando em diferentes tamanhos de tela.

### Desktop

No desktop, os conteúdos são distribuídos de forma mais ampla, permitindo a apresentação dos livros em cards e das unidades lado a lado.

### Smartphone

No smartphone, os elementos são reorganizados verticalmente para facilitar a leitura e a interação em telas menores.

A interface foi testada em um **dispositivo móvel real**, verificando o funcionamento dos principais elementos e a adaptação das diferentes seções.

---

## ♿ Acessibilidade

A acessibilidade foi considerada durante o desenvolvimento da interface.

Entre as práticas utilizadas estão:

- `alt` nas imagens;
- HTML semântico;
- Elementos interativos acessíveis;
- Navegação por teclado;
- Indicação visual de foco;
- Contraste entre texto e fundo;
- Organização clara das informações.

O foco de teclado recebeu um destaque visual em **dourado**, facilitando a identificação do elemento atualmente selecionado durante a navegação.
